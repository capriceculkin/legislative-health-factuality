Ontario Hansard search backend. Identified by inspecting browser network traffic on the OLA search page. Accepts OData filter expressions.

Stage 3 — Predication Extraction
Complete — not on GitHub
US Predications
data/dbpedia_pipeline/us/predications.json
215,412
SVO triples — 36.9% of sentences
spaCy extracts Subject-Verb-Object before Spotlight runs. Spotlight then runs on subject and object strings only, never on the full sentence.
Why predications first
OLD: Spotlight on full sentence
"The OMA, which represents 30,000 physicians,
endorsed this legislation."
Entities: OMA, Physician, Legislation
Pair (OMA, Physician) confirmed by DBpedia
but the speaker was not claiming this.

NEW: spaCy extracts predication first
subject: Ontario Medical Association
verb:    endorsed
object:  legislation
Spotlight on those two strings only.
Pair (OMA, Legislation) not in DBpedia.
Correctly not supported.
Example predications
TEXT: "Last session Congress passed an
omnibus veterans bill, H.R..."
  subject: Congress
  verb:    pass
  object:  an omnibus veterans bill

TEXT: "Their work adheres to the highest
standards of objectivity..."
  subject: Their work
  verb:    adhere
  object:  the highest standards
What is excluded
Existential root verbs: be, have, do, seem
No subject or no object found
Subject equals object
Entities in relative clauses or parentheticals

Stage 5 — SPARQL Verification
Pending — all jurisdictions
DBpedia SPARQL Results Cache
data/dbpedia_pipeline/{jurisdiction}/dbpedia_results.json
One result per unique entity pair
cached — query DBpedia once, apply to all sentences containing that pair
Local Virtuoso at localhost:8890. English and French DBpedia both loaded. Checks for any direct triple connecting the two entities in either direction.
SPARQL query template
SELECT ?a ?b ?p WHERE {
  VALUES (?a ?b) { (<URI_A> <URI_B>) }
  { ?a ?p ?b } UNION { ?b ?p ?a }
}
Supported example
Pair: (dbpedia:Canada, dbpedia:United_States)
Result: dbo:neighboringMunicipality
Supported: True
Not supported example
Pair: (dbpedia:Ontario_Medical_Association,
       dbpedia:Legislation)
Result: no triples found
Supported: False
The OMA endorsing legislation is rhetorical.
The relationship is not in DBpedia.
