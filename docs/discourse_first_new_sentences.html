Discourse first, then a tree per unit

Drawn the way Mann and Thompson draw discourse trees: a line spans the units a relation covers; the main part hangs from it on a straight line; the supporting part is joined to it by a curved arrow labelled with the relation; equal parts both hang on straight lines. In place of each unit's number is that unit's own constituency tree, and under it the subject | verb | object lines read from it. Each unit's tree comes from parsing that unit on its own.
