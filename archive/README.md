# archive

Everything here was moved out of the working folders on Nov 13, 2026 so the repo is easier to read. Nothing was
deleted and nothing was changed. `MOVES.tsv` lists every item: where it was, where it is now, how many files, and why.
Each item keeps its old path under its group folder, so putting one back is one move.

- `top_level_loose_files/`: one-off scripts, old logs and old outputs that sat at the top of the repo.
- `data_snapshots/`: copies of the data taken before each fix in September and October (19 GB). Not tracked by git.
- `script_backups/`: timestamped copies of scripts made before each change, and duplicate downloads.
- `scripts_not_used/`: scripts that were already set aside and that nothing refers to.
- `old_document_versions/`: earlier versions of the CLAY deck and speaker notes, and slides made to paste in.
- `old_outputs/`: outputs from before a rerun, and the first start of the full run that was stopped.
- `before_reorg_2026-11-13_scripts_notebooks_readmes.tar.gz`: scripts, notebooks and READMEs exactly as they were
  before the folders were renamed (v3, v4, v6) and before any path was updated.

The scripts in here still have their old paths inside them (scripts/v3 and so on). Some will not run from here without
a small path change. If none of this is needed after the fall deliverable, the whole folder can be deleted in one go.
